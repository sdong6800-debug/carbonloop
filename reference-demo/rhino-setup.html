RHINO 8 / LOCAL CONNECTOR

把 Rhino 模型发送到 CarbonLoop

安装原生 Rhino 8 插件后，Rhino 会直接建立本地工作台并在进程内发布模型；不再需要黑色连接窗口或 Python 宏。

下载 Rhino 插件 ↓下载教师安装手册（PDF）先查看网页演示 →
01

安装插件

关闭 Rhino，双击下载的 CarbonLoop-Rhino-0.2.0.rhi，按安装提示完成。

02

打开工作台

重新打开 Rhino，在命令栏输入 CarbonLoop。插件会直接打开本机工作台。

03

创建可选按钮

如需工具栏按钮，在 Rhino 输入 Macros，新建“发送到 CarbonLoop”，宏使用下方原生命令。

04

发送并核对

预选构件，或在命令中选择当前图层/整个模型。运行后网页会收到并自动打开最新模型。

Rhino 宏命令

! _CarbonLoopSend

本地工作台地址：http://127.0.0.1:8513/demo.html

当前版本可以做什么？

  • 读取选择范围、Rhino 单位、稳定对象 ID、图层、材料名称、三维包围盒与封闭实体净体积。
  • 原生插件在 Rhino 进程内发布数据，并在后续图层、构件与材质变化时自动同步当前范围。
  • 网页供建筑师核对构件分类、楼层和碳材料映射；自定义命名仍需人工确认。
  • 结构求解、双向高亮、网页修改写回 Rhino 仍属于后续版本。
