# Rhino 8「发送到 CarbonLoop」按钮

当前交付使用原生 Rhino 8 插件。插件会在 Rhino 启动后建立本地 CarbonLoop 工作台和模型接收服务；不需要 Node.js、黑色连接窗口或 Python 宏。

## 第一次设置

1. 关闭 Rhino。
2. 双击 `CarbonLoop-Rhino-0.2.0.rhi`，按 Rhino 安装提示完成安装。
3. 重新打开 Rhino，在命令栏输入 `CarbonLoop`。浏览器应打开 `http://127.0.0.1:8513/demo.html`。
4. 可选：在 Rhino 8 输入 `Macros`，新建一个宏，名称填 `发送到 CarbonLoop`。
5. 宏命令只填写：

```text
! _CarbonLoopSend
```

6. 把宏拖到 Rhino 工具栏。旧版指向 `CarbonLoopSend.py` 的按钮会由兼容入口转接到同一个原生命令，但建议直接使用上面的宏。

安装包会自动建立工作台连接。若启动时端口暂时被占用，关闭旧版黑色连接窗口后等待约 5 秒，插件会自动重连。

## 使用

1. 在 Rhino 里先选择构件，或直接点击按钮后选择“指定图层 / 整个模型”。
2. 点击「发送到 CarbonLoop」。模型在 Rhino 进程内完成整理和发布，不再经 Python HTTP 上传整栋模型。每次发送都会产生新的唯一编号。
3. 返回本地工作台 `http://127.0.0.1:8513/demo.html`。网页会在约 2 秒内显示“Rhino 已连接”，自动打开最新模型的核对界面。公网网页用于查看产品；真实 Rhino 数据只留在本机连接中。
4. 插件会先用 `rhino-semantic-profile.json` 把英文/中文图层、对象名称和材料名称翻译成 CarbonLoop 分类，并自动排除标注、尺寸等辅助对象。
5. 网页会按“图层＋原始材料”分组显示建议及置信度。建筑师只需按组核对一次，不需要逐个处理数百个对象；仍未识别的分组可在网页中修改。浏览器会在本机记住已修改的项目映射，同一命名组合下次会直接复用，仍可再次核对或覆盖。

## 当前真实边界

- 已实现：原生 `.rhp/.rhi` 插件、范围选择、稳定 GUID、Rhino 单位、包围盒、图层/楼层标签、可获取的渲染材料名称、封闭几何净体积、本地发布、网页协议校验，以及基于本地语义词典的构件/材料初步识别、置信度、辅助对象排除和后续自动同步。
- 需人工核对：系统提出的构件与材料分组建议、楼层归属，以及词典尚未覆盖的事务所自定义命名。
- 可维护规则：`rhino-semantic-profile.json` 是 Rhino 与 CarbonLoop 之间的语义映射手册。新增事务所常用英文缩写时，可在这里扩充，而不是修改 900 个对象。
- 平面与线性对象：也会发送、显示和分类。为看得见而补出的预览厚度不参与碳计算；只有 Rhino 能提供真实封闭体积或后续补齐真实厚度/工程量后才计算。
- 尚未实现：双向高亮、把网页修改写回 Rhino、正式结构求解。
- 包围盒只用于网页预览；封闭几何能取得净体积时，碳计算使用净体积。开放曲面等没有净体积的对象会保留几何，但不能假装已有材料工程量。

## 出现 `发送失败: timed out`

这表示按钮仍在执行旧版 Python 宏。把按钮宏改为 `! _CarbonLoopSend`，或使用已更新的兼容脚本。不要再启动旧版黑色连接窗口。
