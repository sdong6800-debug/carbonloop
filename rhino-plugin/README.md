# CarbonLoop for Rhino 8

CarbonLoop 是面向小型建筑事务所的 Rhino 8 前期隐含碳分析插件。建筑师在 Rhino 中选择构件、当前图层或整个模型，插件会读取图层、对象名称、材料、体积与单位，并把结果送入本机 CarbonLoop 工作台进行核对、碳计算和方案比较。

## 这是真插件，不是网页演示宏

- 安装后由 Rhino 自动加载并启动本地连接。
- Rhino 启动后自动出现 CarbonLoop 面板，可直接点击“发送已选构件”。
- 不需要再双击 `启动 Rhino 连接.cmd`，也不需要保持黑色窗口开启。
- Rhino 启动并加载插件后会自动建立本地连接，不再需要单独运行黑色连接窗口。
- `CarbonLoopSend` 读取当前 Rhino 文档；网页每次收到新的 transmission ID 后自动刷新。
- 第一次发送会确定本次分析范围；之后在 Rhino 中新增/删除构件、改图层或改材质，会在约 2 秒内自动同步到网页。
- 自动同步会保留来源未变化对象的人工核验；新增或材料/图层语义变化的对象才重新待核对。
- 如果 8513 / 8515 已由兼容的 CarbonLoop 实例使用，插件会自动复用该实例；新发送的 Rhino 文件会替换上一份模型和旧核验状态。
- 完整网页随插件安装在本机，模型数据不会因这条本地链路自动上传到公网。
- 当前版本是前期决策工具，不替代注册结构工程师的最终核算与签字。

## 使用

1. 在 Rhino 8 中选中需要分析的对象。
2. 在命令行输入 `CarbonLoopSend`。如果没有预选对象，可选择当前图层、整个模型或重新选择。
3. 插件自动打开 `http://127.0.0.1:8513/demo.html`。
4. 在网页中核对自动识别的构件类型和材料，然后进入碳分析。
5. 输入 `CarbonLoop` 可随时重新打开工作台。

## Rhino 模型如何被理解

这不是让大模型凭空猜测的 prompt，而是一套可检查的“模型翻译规则”。识别优先级如下：

1. 对象自定义属性 `CarbonLoop.Type`、`CarbonLoop.Material`、`CarbonLoop.Floor`；
2. Rhino 对象名称；
3. 完整图层路径与末级图层名；
4. 无法确定时保留“待核对”，不会伪造材料或工程量。

对象所属图层用于判断“它是什么构件”，Rhino 对象或图层继承的材质用于判断“它是什么材料”。例如 `Building::Floors::ext.Finish` 仍是楼板构件，`Carrara marble` 是它的饰面材料，两者不会混成同一个分类。建筑师修正一次后，网页会按“完整图层＋原始材料”记住该项目的映射。

语义规则保存在 `rhino-semantic-profile.json`，可以继续补充中英文图层词汇，而不需要改动网页。

## 碳计算与 AI 的分工

网页当前核对 KBOB/ecobau 2022 v9.0 的 15 条材料来源记录。碳数值由程序按净量、密度和因子确定性复算；AI 只接收结果摘要或受限构件资料，用于解释主要来源、缺项、修改影响与下一步，不参与乘法也不能把部分小计说成完整生命周期。

Release 另附 `CarbonLoop-AI-Connector-0.2.1.zip`。它需要 Node.js 20+ 和用户自己的 DeepSeek API Key；服务仅监听本机 8514，密钥不进入 Rhino 文件、网页或 Excel。

## 本地开发与构建

安装 Rhino 8 后，在 PowerShell 中运行：

```powershell
.\build-plugin.ps1
```

脚本会编译 `CarbonLoop.Rhino.rhp`、复制当前网页和语义词典，并用 Rhino 自带的 Yak 工具生成可安装包。生成结果位于 `dist`。

## 核心命令

| 命令 | 作用 |
|---|---|
| `CarbonLoop` | 启动本地服务并打开网页工作台 |
| `CarbonLoopSend` | 发送预选构件；未预选时询问分析范围 |

## 当前产品边界

插件可可靠读取 Rhino 中的对象、图层、已赋材料、单位、包围盒和封闭几何净体积。只有包围盒而没有封闭净体积的对象可以在网页中预览与核对，但不会拿包围盒体积冒充工程量。结构安全部分目前是规则筛查与 AI 辅助解释，不是有限元求解器。
