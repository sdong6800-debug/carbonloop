# CarbonLoop for Rhino 8

CarbonLoop 是面向小型建筑事务所的 Rhino 8 前期隐含碳分析插件。0.3.1 预发布版在发送前打开 Rhino 内的图层与材料核验窗口，确认后才把结果送入网页。词典、网页联动和本地服务有自动化检查；Rhino 内完整点击流程仍有待验收项，详见核验验收说明。

## 这是真插件，不是网页演示宏

- 安装后由 Rhino 自动加载并启动本地连接。
- 输入 `CarbonLoopSend` 或使用已有工具栏按钮打开核验。旧 Eto 面板源文件当前不参与编译。
- 不需要再双击 `启动 Rhino 连接.cmd`，也不需要保持黑色窗口开启。
- Rhino 启动并加载插件后会自动建立本地连接，不再需要单独运行黑色连接窗口。
- `CarbonLoopSend` 读取当前 Rhino 文档；网页每次收到新的 transmission ID 后自动刷新。
- 第一次发送确定分析范围；来源未变化对象的几何修改仍自动同步。
- 新对象、改图层、改名称或改材质使相关确认失效；命令行提示运行 `CarbonLoopSend`，确认前暂停发送。
- 如果 8513 / 8515 已由兼容的 CarbonLoop 实例使用，插件会自动复用该实例；新发送的 Rhino 文件会替换上一份模型和旧核验状态。
- 完整网页随插件安装在本机，模型数据不会因这条本地链路自动上传到公网。
- 当前版本是前期决策工具，不替代注册结构工程师的最终核算与签字。

## 使用

1. 在 Rhino 8 中选中需要分析的对象。
2. 在命令行输入 `CarbonLoopSend`。如果没有预选对象，可选择当前图层、整个模型或重新选择。
3. Rhino 中出现核验表，检查构件类型、材料类别和建议。“勾选全部明确匹配”仅处理无歧义词典匹配；拼写建议需逐组确认。
4. 如需纠正名称，点“填入本组拼写建议”。材料修正存入本组对象的 CarbonLoop 属性；图层改名另需明确勾选全图层影响范围。
5. 勾选“确认本组”后点击“确认修改并发送”。不确定项可选择未确定并确认保留；网页继续显示待核验。
6. 插件打开网页。Rhino 明确确认的分类不会被旧浏览器映射覆盖，也不要求再次确认相同材料。
7. 保存 `.3dm` 文件以保留确认属性；输入 `CarbonLoop` 可以重新打开工作台。

## Rhino 模型如何被理解

这不是让大模型凭空猜测的 prompt，而是一套可检查的“模型翻译规则”。识别优先级如下：

1. 对象自定义属性 `CarbonLoop.Type`、`CarbonLoop.Material`、`CarbonLoop.Floor`；
2. Rhino 对象名称；
3. 完整图层路径与末级图层名；
4. 无法确定时保留“待核对”，不会伪造材料或工程量。

对象所属图层用于建议构件类型，对象或图层继承材质用于建议材料。Finish 图层默认倾向饰面类别；需要归为楼板时，在 Rhino 核验表中明确选择。用户确认的 `CarbonLoop.Type` 优先于网页的 Finish 规则。

词典支持 wood、timber、lumber 等别名。拼写建议采用有长度限制的编辑距离，可对 timbre、wod、slaab、colum 提出候选；短缩写和中文不自动纠错，冲突名称要求人工选择。此功能在本地运行，不消耗 API，也不代表已验证材料性能。

核验结果写入 `CarbonLoop.Type`、`CarbonLoop.MaterialCategory`、`CarbonLoop.Material` 等对象属性，保留原始渲染材质名，并记录来源指纹与时间。原材质或图层变化会使旧确认失效。

语义规则保存在 `rhino-semantic-profile.json`，可以继续补充中英文图层词汇，而不需要改动网页。

## 碳计算与 AI 的分工

网页当前核对 KBOB/ecobau 2022 v9.0 的 15 条材料来源记录。碳数值由程序按净量、密度和因子确定性复算；AI 只接收结果摘要或受限构件资料，用于解释主要来源、缺项、修改影响与下一步，不参与乘法也不能把部分小计说成完整生命周期。

新版另附 `CarbonLoop-AI-Connector-0.3.1.zip`。它需要 Node.js 20+ 和用户自己的 DeepSeek API Key；发送前核验无需启动此服务。

## 本地开发与构建

安装 Rhino 8 后，在 PowerShell 中运行：

```powershell
.\build-plugin.ps1 -OutputDirectory .\dist\review-build
```

脚本会编译 `CarbonLoop.Rhino.rhp`、复制当前网页和语义词典，并用 Rhino 自带的 Yak 工具生成可安装包。生成结果位于 `dist`。

## 核心命令

| 命令 | 作用 |
|---|---|
| `CarbonLoop` | 启动本地服务并打开网页工作台 |
| `CarbonLoopSend` | 发送预选构件；未预选时询问分析范围 |

## 当前产品边界

插件可可靠读取 Rhino 中的对象、图层、已赋材料、单位、包围盒和封闭几何净体积。只有包围盒而没有封闭净体积的对象可以在网页中预览与核对，但不会拿包围盒体积冒充工程量。结构安全部分目前是规则筛查与 AI 辅助解释，不是有限元求解器。
