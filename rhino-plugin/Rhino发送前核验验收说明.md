# Rhino 发送前核验验收说明

版本：0.3.1 预发布测试版。发布整理日期：2026-10-25。

## 使用流程

1. 保存模型，通过 Windows ZIP 中的安装脚本安装 Yak 包，再重新打开 Rhino 8。
2. 选中模型对象，运行 `CarbonLoopSend`。
3. 核验表显示原始图层、原材质、建议构件类型、建议材料类别和匹配理由。
4. 对明确词典匹配可以批量勾选；对拼写、冲突和未知项逐组检查。下拉菜单允许自行选择。
5. “填入本组拼写建议”可以填入纠正后的碳分析材质名或图层名；修改后需要重新勾选确认。
6. 修改图层名需另行勾选同层全部对象的影响范围。碳分析材料名只写入本组对象属性，原共享渲染材质保留。
7. 点击“确认修改并发送”。网页接收已确认类别；工程量或碳因子缺失仍分别提示。

本次词典和拼写建议在本地完成，不涉及模型 API。人工确认只确定分类，不证明材料产品或工程性能等效。

## 已执行的检查

- 插件编译。
- 28 项词典与编辑距离检查：别名、大小写、木材具体品类、换位及缺字拼写（含图层名 `timer` → `timber`）、未知、歧义与辅助对象，以及原材质优先于图层提示。
- 材料接入检查：Rhino 确认优先、显式未知保留、失效和无效类别拒绝、原始名称保留、净量计算。
- 无头浏览器联动：Rhino 确认进入网页、无需重复确认、旧浏览器映射不覆盖新确认、未确定状态保留。

自动化检查不代表真实 Rhino 窗口中的全部交互已验收。此前独立无窗口 Rhino 引擎在初始化时直接退出。2026-10-22 安装 0.3.1 后，用户反馈拼写建议按钮问题已解决；纠正后确认、发送、网页接收的最新完整流程，以及撤销、锁定对象等仍需实测。本次以预发布版提供试用，不标记为全部通过。

## 安装后的实际验收

| 操作 | 预期结果 |
| --- | --- |
| 新建 slaab 图层，材质命名 timbre，放入两个封闭对象 | 一组显示 2 个对象，提示 slab / timber 候选；不自动确认 |
| 不勾选确认，直接点击发送 | 提示核验，不写入属性、不发布 |
| 点击关闭核验 | 取消后原模型属性保持不变，不发布 |
| 填入 timbre → timber，勾选并确认发送 | 对象 CarbonLoop 属性保存类别与纠正名称，原渲染材质仍为 timbre，网页接收确认 |
| 修改图层名而未勾选全层影响范围 | 阻止保存并说明原因 |
| 明确允许后把 slaab 改为 slab | Rhino 图层名改变，同层影响范围可见 |
| 再次发送未变化的模型 | 既有确认已勾选，允许重新检查 |
| 修改同一对象的原材质为 Glass | 旧确认失效，自动同步暂停；再次核验显示 Glass，不沿用旧 timber |
| 只修改已确认对象几何 | 确认仍有效，正常同步工程量 |
| 在 Rhino 中撤销确认修改 | 复核图层与对象属性恢复，撤销产生的来源变化不会绕过核验 |
| 锁定或引用对象无法写入 | 显示失败并尝试恢复原属性，不发布半完成结果 |
| 同时打开两个 Rhino 模型，各自发送 | 核验使用当前文档；网页收到最新一次确认的文档和范围 |
