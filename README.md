# CarbonLoop

CarbonLoop 是一个面向小型建筑事务所的 Rhino 8 前期隐含碳分析插件：建筑师选择部分构件、某个图层或整个模型，插件自动读取几何、图层和已赋材料；建筑师只核对不确定项，然后查看可追溯的碳排小计、探索候选修改，并把结果导出为 Excel。

> 当前版本：`0.2.0`。这是前期决策工具，不是完整 LCA、结构求解器或规范合规证明。

## 一次完整流程

1. **Rhino 发送**：运行 `CarbonLoopSend`，选择“已选构件 / 当前图层 / 整个模型”。
2. **自动整理**：插件根据对象属性、名称、完整图层路径和材料名识别梁、板、柱、墙及材料；标注和辅助对象自动排除。
3. **人在回路核验**：网页按“构件类型＋原材料来源”分组。建筑师可以批量确认，也可以直接修正；相同项目命名会在本机记住。
4. **确定性碳计算**：材料净体积 × 密度 × 碳因子。每个构件可以展开数量、因子、原表行号和代理假设；缺项不按零排放。
5. **AI 解释与候选研究**：程序先计算，AI 只解释覆盖率、主要来源、缺项与下一步，或在受限规则下提出候选；AI 不改写计算数字。
6. **探索与比较**：修改一个构件的尺寸或材料，立即查看构件和所选范围的碳变化；结构规则只做风险筛查，不能代替结构工程师。
7. **导出**：下载 Excel，保留模型范围、构件明细、碳因子、候选差值、AI 依据和待验证事项。

## Rhino 插件特性

- Rhino 8 原生 `.rhp/.rhi` 插件，启动时自动建立本机工作台；不再依赖旧版 Python 宏或黑色连接窗口。
- 首次发送确定分析范围；对象、图层或材质改变后约 1–2 秒自动同步。
- 8513 / 8515 端口暂时被占用时每 5 秒自动重连，无需重启 Rhino。
- 自动同步保留未变化对象的人工核验；只有新增或语义变化的对象重新进入核验。
- 使用稳定 Rhino GUID、模型单位、完整图层路径、对象/图层继承材质和封闭几何净体积。
- 开放曲面与线性对象可以预览和分类，但没有真实工程量时不会拿包围盒体积冒充材料净量。

## 材料与碳因子

当前引用 `KBOB/ecobau 2022 v9.0` 工作簿中的 15 条已核对记录，覆盖：

- 通用与特定配方混凝土
- 钢筋、裸型钢、裸钢板
- 胶合木、CLT、针叶实木
- 黏土砖、加气混凝土块、水泥砌块
- 无镀膜平板玻璃、裸铝型材、石膏板
- 抛光天然石材（含明确标注的 Carrara 大理石早期代理）

当前结果只汇总来源中的“材料生产＋处置”列，不是完整生命周期。运输、施工、维护、更换、运行、回收收益和未建模钢筋等缺项会单列。

## AI 架构

CarbonLoop 把 AI 与确定性计算分开：

- **规则 / Skill 层**：单位校验、类型映射、工程量有效性、允许修改范围和输出校验。
- **RAG 层**：结构筛查只检索获准知识片段，并要求模型返回本轮检索中的引用 ID。
- **大模型层**：解释碳结果、回答修改影响、组织下一步问题；使用 JSON Schema 限制输出。
- **计算层**：所有碳数值与候选差值由程序复算，不采用模型编造的数字。
- **人在回路**：发送资料、应用候选和保留方案都需要建筑师明确确认。

本地 AI 连接只监听 `127.0.0.1:8514`。API Key 通过窗口内存传给子进程，不写入网页、项目文件或导出；关闭连接窗口后清除。运行 AI 连接器需要 Node.js 20 或更高版本。

## 安装

1. 从 Release 下载 `CarbonLoop-Rhino-0.2.0.rhi`。
2. 关闭 Rhino，双击 `.rhi`，按提示安装后重新打开 Rhino 8。
3. 在 Rhino 命令栏输入 `CarbonLoop`，浏览器打开 `http://127.0.0.1:8513/demo.html`。
4. 选择构件并运行 `CarbonLoopSend`。
5. 可选 AI：解压 `CarbonLoop-AI-Connector-0.2.0.zip`，进入 `ai-service` 文件夹并双击 `connect-deepseek.cmd`，输入自己的完整 DeepSeek API Key 后保持窗口打开。

详细说明见 [rhino-plugin/安装说明.md](rhino-plugin/安装说明.md)，演示脚本见 [演示步骤.md](演示步骤.md)。

## 构建

需要 Rhino 8 和项目本地 .NET SDK：

```powershell
cd rhino-plugin
.\build-plugin.ps1
```

输出位于 `rhino-plugin/dist/`：

- `CarbonLoop-Rhino-0.2.0.rhi`
- `carbonloop-rhino-0.2.0-any-win.yak`
- `CarbonLoop-AI-Connector-0.2.0.zip`
- `安装说明.md`

## 核心验证

项目包含数据源、接口、Rhino 协议和浏览器端到端测试。发布前至少验证：

- KBOB 工作簿 SHA-256 与 15 条原始行数据一致；
- Rhino 发送、自动同步、核验保留与材料变化回退；
- 构件分类、材料分组和批量确认；
- 碳结果、缺项、候选修改、对比和 Excel 导出；
- AI 输出 Schema、来源边界和本机接口保护；
- `.rhi` 解压后的独立本地服务启动。

## 目录

- `rhino-plugin/`：Rhino 8 C# 插件、打包脚本和安装说明
- `reference-demo/`：随插件安装的本机网页工作台和浏览器测试
- `integration/rhino/`：语义词典及旧版兼容资料
- `ai-service/`：本机 DeepSeek/OpenAI 接口、结构 RAG 和确定性截面检查
- `data/`：早期案例与材料数据；当前插件碳因子以 `reference-demo/sources/` 中的 KBOB 工作簿为准

## 已知边界

- Rhino 与网页目前不是双向高亮；网页修正不会写回 Rhino。
- 自由建模文件的构件语义依赖命名、图层、材质和对象属性；系统无法可靠判断时必须人工确认。
- KBOB 为瑞士市场参考，不能替代项目地区、供应商或产品 EPD。
- 结构模块是前期影响筛查和协作清单，不是有限元分析或工程签字。
- 本地 AI 服务尚无公网鉴权，不应直接暴露到云服务器或端口转发。
